# 記帳本

給自己用的手機記帳 Web App。存款與信用卡分開管理、一筆消費可拆成多個分類、信用卡分期與每期卡費自動計算、收到銀行帳單時對帳補記，並有每月分類報表。

技術：Node.js（Express）＋ PostgreSQL（Neon 免費方案），前端是不需要打包的原生 JavaScript，部署在 Render 免費方案，加到 iPhone 主畫面就能像 App 一樣使用。

## 功能

- **總覽**：存款餘額、信用卡未繳、貸款剩餘本金、淨資產、本月支出與分類比例、最近交易
- **快速動作**：提領現金、存入現金、繳卡費、繳學貸
- **帳戶**：存款（含現金）、信用卡、貸款分開顯示，餘額即時計算；存款可「校正餘額」
- **信用卡自動扣繳**：只有「已對帳」的帳單會在繳款日從指定帳戶自動扣款，金額為對帳時勾選的總額
- **貸款（學貸）**：每月自動扣款，整筆從存款轉到貸款；剩餘本金以銀行為準，可隨時「更新剩餘本金」；也可手動記錄繳款
- **核對自動扣款**：自動扣款產生的紀錄會標成「待核對」，對照銀行明細確認或修改實際金額
- **代墊**：品項可標記為代墊並填對象，不算進支出、預算和專項；有「待收回」清單，收回時錢回到指定帳戶且不算收入
- **預算**：每月固定支出清單（房租、訂閱等，可自動記帳）＋各分類每月預算，即時顯示剩餘；代墊不扣預算
- **專項**：每筆明細都能掛專項（例如日本行），看各專項花費、收入、類別佔比
- **帳戶外觀**：色環選色、最近用過的顏色；帳戶圖示可用文字、線條圖示、表情符號或上傳圖片
- **拖曳排序**：帳戶、分類按住拖曳即可排序
- **美甲（個人工作室）**：客戶、施做紀錄（預約成功／已付訂金／施做完成，完成時自動記收入）、進貨（自動加庫存並記支出）、庫存與拿取紀錄；每月自動撥 10% 到收入袋
- **報表**：月報（比較上月）、類別明細與 6 個月趨勢、近 12 個月趨勢、年度總覽、資產變化；滾輪選月份；匯出 Excel／CSV
- **記一筆**：簡單模式（金額＋點類別）與明細模式（一張收據拆成多筆，每筆各自選類別、專項、代墊）；也能記收入、轉帳
- **信用卡帳單**：依結帳日自動把消費歸到對應期別；帳單頁顯示一般消費＋本期分期
- **分期**：零利率、年利率（等額本息）、每期固定手續費；每期本金與利息自動入帳到對應帳單
- **對帳**：輸入銀行帳單金額，勾選有出現的消費（沒勾的移到下期），補記沒記到的海外刷卡，差額歸零才完成
- **報表**：每月各分類金額、筆數、佔比與圓環圖
- **分類管理**：新增、改名、換顏色、排序、封存
- 密碼登入（單一使用者）

## 本機執行

需要 Node.js 22 以上。

```bash
npm install
cp .env.example .env      # 填入 DATABASE_URL、APP_PASSWORD、SESSION_SECRET
npm run db:init           # 建立資料表與預設分類（已建立過會自動略過）
npm run dev               # http://localhost:3000
```

`DATABASE_URL` 可以直接用 Neon 的連線字串，也可以用本機的 PostgreSQL。

## 從舊版升級

已經在使用的資料庫，到 Neon 的 SQL Editor 執行 `db/migrations/upgrade_to_latest.sql`（包含 002～005，重複執行也不會出錯），再更新程式碼。

如果只想執行還沒跑過的部分，也可以依序執行個別檔案：

1. `db/migrations/002_cash_loans_autopay.sql`：現金、貸款、自動扣款
2. `db/migrations/003_advances_budget_projects_nail.sql`：代墊、預算、專項、美甲收入袋
3. `db/migrations/004_details_icons_nail_reports.sql`：明細層級專項、帳戶圖示、美甲客戶／施做／進貨／庫存
4. `db/migrations/005_discounts.sql`：折扣

全新的資料庫只要執行 `db/schema.sql`。

## 建立 Neon 資料庫

1. 到 [neon.com](https://neon.com) 註冊並建立一個 Project（Region 選離台灣近的，例如 Singapore）。
2. 在 Project 的 **Connect** 取得連線字串（`postgresql://...?sslmode=require`），填到 `.env` 的 `DATABASE_URL`。
3. 本機執行 `npm run db:init` 建立資料表。
   也可以把 `db/schema.sql` 的內容貼到 Neon 的 SQL Editor 執行，效果一樣。

## 部署到 Render

1. 把這個專案推到 GitHub：

   ```bash
   git init
   git add .
   git commit -m "記帳本初版"
   git branch -M main
   git remote add origin https://github.com/<你的帳號>/<repo 名稱>.git
   git push -u origin main
   ```

2. 在 Render 選 **New → Blueprint**，選這個 repo，Render 會讀取 `render.yaml` 自動建立服務。
   （也可以選 **New → Web Service**：Build Command `npm install`、Start Command `npm start`。）
3. 在服務的 **Environment** 設定：
   - `DATABASE_URL`：Neon 連線字串
   - `APP_PASSWORD`：登入密碼
   - `SESSION_SECRET`：Blueprint 會自動產生；手動建立的話自己填一串長的隨機字
4. 部署完成後打開網址，用 `APP_PASSWORD` 登入。

Render 免費方案閒置約 15 分鐘會休眠，之後第一次打開要等幾十秒喚醒；Neon 閒置時也會自動暫停，第一個請求會稍慢一點。

## 使用說明

### 信用卡的結帳日與繳款日

- 消費日在結帳日（含）之前，算進當月結帳的那一期；之後就算下一期。
- 繳款日如果比結帳日晚，視為同一個月繳款（例如結帳 2 日、繳款 20 日）；否則視為下個月（例如結帳 25 日、繳款 10 日）。
- 「信用卡未繳」計算已入帳的消費（日期已到，或該期已對帳）減掉繳款。

### 對帳

收到銀行帳單後，到信用卡的本期帳單按「開始對帳」：

1. 輸入銀行帳單的應繳金額。
2. 勾選帳單上有出現的消費；沒勾的會在完成對帳後自動移到下一期。
3. 帳單上有、但自己沒記到的（海外刷卡、自動扣款）用「補一筆」補上；小額差額可以一鍵記成「國外交易手續費」。
4. 差額為 0 時按「完成對帳」，之後再按「記錄繳款」從存款帳戶轉帳到信用卡。

### 提領現金、存入現金

先建立一個存款帳戶並勾選「這是現金（錢包）」。之後總覽的「提領現金」「存入現金」會自動帶入銀行帳戶和現金帳戶，只要輸入金額。這些是轉帳，不會算進支出。

### 信用卡自動扣繳

在信用卡設定裡選「自動扣繳帳戶」。到了繳款日：

- 已對帳的帳單：自動從扣繳帳戶轉帳到信用卡，金額是對帳時勾選＋補記的總額，帳單標成已繳款，扣款紀錄標成「待核對」。
- 還沒對帳的帳單：不會扣款，帳戶頁會提醒你先對帳。

對帳時「銀行帳單金額」是選填的，只用來比對；應繳金額由你勾選的項目決定。

### 學貸（貸款帳戶）

新增帳戶時選「貸款」，填目前剩餘本金、每月繳款金額、每月扣款日和扣款帳戶。每到扣款日，整筆繳款金額從扣款帳戶轉到貸款帳戶（標成待核對）。

系統不計算利息。剩餘本金以台銀為準：在帳戶頁按「更新剩餘本金」輸入台銀顯示的數字，系統會自動調整，不算支出。手動記錄繳款時也可以直接填繳完後的剩餘本金。手動繳完後，當月的自動扣款會往後順延一期。

### 核對自動扣款

總覽出現「N 筆自動扣款待核對」時點進去，金額正確就按「正確」，不對就改成實際扣款金額再按「正確」。

### 代墊

記帳時在品項按「代墊」並填上對象（例如聚餐刷卡 1,800：自己 600、小美 600、阿明 600）。卡費仍是 1,800，但支出報表、預算、專項只算你自己的 600。朋友還錢後到「更多 → 代墊待收回」勾選項目、選錢進到哪個帳戶，這筆收回不算收入。

### 預算

「更多 → 預算」：

- 每月固定支出：新增房租、電話費、訂閱等，設定金額、週期、下次扣款日；可勾選「到期自動記帳」（標成待核對），或按「記一筆」手動記。貸款會自動列入。
- 分類預算：按「編輯預算」設定每個分類每月上限；選「每月沿用」是預設值，選「只改這個月」只調整當月。

### 記一筆：簡單模式與明細模式

- 簡單模式：輸入金額、點一個類別，需要時選專項，就能儲存（例如一張蔥油餅）。
- 明細模式：按「拆成明細」，一張收據可以拆成多筆（例如 7-11：三明治 30 食物、水壺 70 家用並掛 #日本行），每筆各自有類別、專項、代墊，總金額自動加總。

### 折扣

明細模式下按「＋ 折扣」，可以輸入折扣金額，或直接輸入收據的實付金額讓系統算出折扣。折扣預設依金額比例分攤到每筆明細（也可以只折某一筆），報表、預算、專項都用折後金額；明細會保留原價，列表展開時可以看到原價和折後價。

### 專項

「更多 → 專項」建立專項，記帳時在每筆明細選專項。專項頁顯示花費、收入、淨額與類別佔比（不含代墊）。結束的專項可以收起來。

### 美甲

底部選單「美甲」，只記個人工作室（公司的薪水請記成「薪資」收入）。第一次使用先設定美甲收入分類、進貨分類、入帳帳戶、收入袋帳戶和比例（預設 10%）。

- 總覽：本月工作室收入、收入袋餘額、本月施做次數、今天和接下來的預約、快用完的庫存。
- 客戶：姓名、電話、生日、備註，來店次數與累計消費。
- 施做紀錄：客戶、日期時間、部位、項目、延甲數量、金額、訂金、狀態。狀態改成「施做完成」時自動記一筆美甲收入，改回其他狀態會一併移除。
- 進貨：店家、日期、付款方式（預設收入袋），每項商品的單價和數量。儲存後庫存自動增加，並記一筆美甲材料支出。
- 庫存：剩餘數量、有效日期、快用完提醒；按「拿取」記錄日期、拿取人、數量。
- 每個月結束後，把上個月美甲收入的 10%（四捨五入到百位，例如 2,134 → 2,100）從入帳帳戶轉進收入袋（標成待核對）。

### 繳上一期的卡費

信用卡帳單頁預設顯示今天所屬的這一期；如果上一期（已結帳）還沒繳，頁面上方會出現提示，點進去就能「記錄繳款」，也可以用標題旁的左右箭頭切換期別。匯入資料時，系統會依繳款紀錄判斷哪些帳單已經繳過；判斷錯誤時，可以在該期帳單按「改回未繳」或「標記為已繳」。

### 已經繳了一部分的分期

新增分期時，在「這筆分期已經繳了一部分？」選已經繳了幾期，並選下一期出現在哪個月的帳單。已繳的期數只做紀錄（不影響卡費餘額、帳單和報表），剩下的期數照常每月入帳，報表按期計算。

### 匯入資料

「更多 → 匯入資料」選擇匯入檔（JSON），確認各信用卡的結帳日、繳款日後按「開始匯入」。匯入會清空目前的帳戶、交易、預算、專項、美甲資料（分類保留），再用匯入檔重建；信用卡刷卡依設定的結帳日分期，繳款日已過的帳單標成已繳款。

之後在信用卡的帳戶設定修改結帳日或繳款日，系統會自動依新的日期重新分期（已經對帳過的帳單不會被動到）。

### 刪除

- 交易：在「所有交易」往左滑刪除單筆，或按「選取」一次刪除多筆；編輯頁底部也能刪除。刪除前會列出影響（帳單、專項、預算）。
- 分類：刪除時選擇把明細移到其他分類或改成未分類；也可以改成封存。
- 帳戶：建議封存；要永久刪除需輸入帳戶名稱，連同所有交易一起刪除。
- 專項：交易保留，只取消標記。固定支出：左滑或編輯時刪除，已記的交易保留。
- 美甲：客戶可選擇保留或一併刪除施做紀錄與收入；沒有進貨紀錄的商品可以刪除；拿取紀錄可在「拿取」視窗刪除。

### 報表

「更多 → 分類報表」。上方可切換月報、趨勢、年度、資產；中間的月份按鈕會打開滾輪選單，也可以用左右箭頭切換。月報裡點類別可以看明細和近 6 個月趨勢。右上「匯出」可以匯出單月、整年或自訂區間的 Excel（多個工作表）或 CSV。

### 分期

建立分期時會產生一筆「購買紀錄」（不影響卡費餘額）和每一期的入帳交易（本金＋利息，利息歸在「利息」分類）。

報表計算方式可以選：

- **刷卡當月全額**：分類報表在刷卡那個月計入全額，之後每期只計利息。
- **按期攤到每月**：分類報表每個月計入當期本金＋利息。

分期建立後如果要修改，請到帳單頁的分期列表刪除後重建。

## 專案結構

```
db/schema.sql              資料表、計算餘額與報表的 view、預設分類
scripts/db-init.js         建立資料表（--force 會清空重建）
src/server.js              Express 入口、登入、路由
src/auth.js                密碼登入與 cookie 簽章
src/lib/statements.js      信用卡帳單期別計算
src/lib/installments.js    分期本金、利息試算
src/lib/autopay.js         信用卡自動扣繳、貸款每月自動扣款
db/migrations/             既有資料庫的升級 SQL
src/routes/                API
public/                    前端（index.html、css、js/views）
render.yaml                Render 部署設定
```
